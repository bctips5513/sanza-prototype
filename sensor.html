コンパス・ジャイロ・カメラ・位置情報の許可を求めます。映像と値は端末内で表示・記録するだけで、外部へは送信しません（山の一覧の取得だけ Overpass API に現在地付近の範囲を問い合わせます）。

1. 静止テスト（ブレと更新頻度）

スマホを手すりや岩に当てて動かさず、ボタンを押してから10秒待ちます。

2. 方位の正確さ（見えている山に照準を合わせる）

照準（画面中央の十字）を山頂に合わせて、映像の右下の「記録」。押す指のブレを避けるため、押す直前0.15秒を除いた0.7秒間の平均を記録します。向きを変えたり1周回したりしてから同じ山で繰り返すと、ずれの変化も分かります。縦持ち・横持ちの両方で試してください。
